description: "Comdesk Leadを経由せず、携帯端末の電話アプリで架電した場合に、活動履歴へ履歴・録音がどのように残るかをご案内します。"
---

弊社より貸与しているAndroid携帯端末の電話アプリを使用して架電した場合、該当端末がキャリア録音SIMであれば、通話が発生したときに限り、録音がComdesk Leadのシステム上にアップロードされます。

アップロードされた履歴・録音は、「活動履歴」からご確認いただけます。

<Warning>
Comdesk Leadを経由しない発信では、アクティビティ結果が保存されません。架電の際は、できる限りComdesk Leadにログインしてご利用いただくことを推奨いたします。
</Warning>

上図の電話アプリで架電した場合はComdesk Leadを経由しないため、アクティビティ結果が保存されません。そのため、応対者・ステータス・プロジェクトなどは未記載になります。

### 活動履歴の各項目

| 項目名 | 表示されている場合 | 未記載の場合 |
| --- | --- | --- |
| コールタイプ | 上記「コールタイプ」の表のとおり | 上記「コールタイプ」の表のとおり |
| コール日時 | コールした日時 | 未記載にはならない |
| 顧客名 | 架電先の電話番号が1件のリストにのみ登録されている | 架電先の電話番号がリストに登録されていない<br />架電先の電話番号が複数のリストに登録されている |
| 発信先番号 | 電話アプリを使用した携帯電話番号 | 未記載にはならない |
| 発信元番号 | 架電先の電話番号 | 通話が発生していない |
| プロジェクト | - | システムで登録していないため、必ず未記載 |
| 応対者 | - | システムで登録していないため、必ず未記載 |
| ステータス | - | システムで登録していないため、必ず未記載 |
| 担当営業 | 電話アプリを使用した携帯電話番号に紐付けされたユーザー名 | 未記載にはならない |
| 再コール予定 | - | システムで登録していないため、必ず未記載 |
| 通話時間 | 通話した時間 | 通話が発生していない |
| 通話メモ | - | システムで登録していないため、必ず未記載 |
