---
title: "アクティビティ結果の項目を設定する"
description: "架電のあとに記録するアクティビティ結果（応対者・ステータス）の項目を追加する手順を説明します。"
---

アクティビティ結果の項目は、運用に合わせて自由に追加できます。追加した項目は、初期適用で選択したワークグループですぐに使えます。

## 応対者を追加する

<Steps>
  <Step title="アクティビティ結果設定を開く">
    画面左下の歯車アイコンを押します。［Manage］メニューが表示されたら、［アクティビティ結果設定］を選択します。

    <Frame caption="［アクティビティ結果設定］を選択">
      ![Activity 01 Manage Menu 1](/images/activity_01_manage-menu-1.png "Activity 01 Manage Menu 1")
    </Frame>
  </Step>
  <Step title="追加画面を開く">
    ［アクティビティ結果（応対者）］タブを開き、画面右下の［追加］を押します。

    <Frame caption="画面右下の［追加］">
      ![Activity 02 Add Button 1](/images/activity_02_add-button-1.png "Activity 02 Add Button 1")
    </Frame>
  </Step>
  <Step title="項目名を入力して追加する">
    ［通話結果項目追加］画面で、項目名を入力します。必要に応じて、初期適用でワークグループを選択し、［追加］を押します。

    | 項目 | 説明 |
    | --- | --- |
    | 項目名 | 必須入力です。 |
    | 初期適用 | 追加した項目をすぐに使うワークグループを選択します。［全て選択］と［選択解除］で、まとめて切り替えられます。 |

    <Frame caption="［通話結果項目追加］画面">
      ![Activity 03 Add Dialog 1](/images/activity_03_add-dialog-1.png "Activity 03 Add Dialog 1")
    </Frame>
  </Step>
</Steps>

## 応対者の子項目を追加する

応対者は、親子の関係で登録できます。

<Steps>
  <Step title="親にする応対者を選択する">
    一覧で、親にする応対者の左にあるラジオボタンを選択し、［子項目追加］を押します。

    <Frame caption="親にする応対者を選択して［子項目追加］を押す">
      ![Activity 04 Child Button 1](/images/activity_04_child-button-1.png "Activity 04 Child Button 1")
    </Frame>
  </Step>
  <Step title="項目名を入力して追加する">
    ［通話結果項目追加（子項目）］画面で、項目名を入力し、［追加］を押します。［親項目名］には、選択した応対者の名前が表示されます。

    <Frame caption="［通話結果項目追加（子項目）］画面">
      ![Activity 05 Child Dialog 1](/images/activity_05_child-dialog-1.png "Activity 05 Child Dialog 1")
    </Frame>
  </Step>
</Steps>

## ステータスを追加する

ステータスも、応対者と同じ手順で追加できます。［アクティビティ結果（ステータス）］タブを開いて、［追加］を押します。

<Steps>
  <Step title="項目を入力して追加する">
    ［通話結果項目追加］画面で、各項目を入力し、［追加］を押します。

    | 項目 | 説明 |
    | --- | --- |
    | 項目名 | 必須入力です。 |
    | KPI | KPIステータスにする場合は、［KPIステータスに設定］にチェックを入れます。 |
    | 定型文 | 任意入力です。 |
    | 活動履歴表示対象 | ［はい］または［いいえ］を選択します。 |
    | 初期適用 | 追加した項目をすぐに使うワークグループを選択します。 |

    <Frame caption="ステータスの［通話結果項目追加］画面">
      ![Activity 06 Status Add Dialog 1](/images/activity_06_status-add-dialog-1.png "Activity 06 Status Add Dialog 1")
    </Frame>
  </Step>
  <Step title="子項目を追加する（必要な場合）">
    応対者と同じように、親にするステータスを選択して［子項目追加］を押すと、子項目を追加できます。
  </Step>
</Steps>
