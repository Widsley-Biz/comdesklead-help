---
title: "ワークグループを作成する"
description: "ワークグループを作成する手順を説明します。"
---

ワークグループごとに、表示するリスト項目、応対者、ステータスを分けられます。<br />例：販売する商材（toB・toCなど）ごと、部署ごと

<Steps>
  <Step title="ワークグループ管理画面を開く">
    画面左下の歯車アイコンを押します。［Manage］メニューが表示されたら、［ワークグループ管理］を選択します。

    <Frame caption="Manageメニュー">
      ![Workgroup Create 01 Manage Menu](/images/workgroup-create_01_manage-menu.png "Workgroup Create 01 Manage Menu")
    </Frame>
  </Step>
  <Step title="［追加］を押す">
    ワークグループ管理画面の右下にある［追加］を押します。ワークグループ追加画面が表示されます。

    <Frame caption="ワークグループ管理画面">
      ![Workgroup Create 02 Add Button](/images/workgroup-create_02_add-button.png "Workgroup Create 02 Add Button")
    </Frame>
  </Step>
  <Step title="ワークグループ名を入力して追加する">
    ［ワークグループ名］を入力し、［追加］を押します。［備考］の入力は任意です。

    ［追加］は、ワークグループ名を入力すると押せるようになります。

    <Frame caption="ワークグループ追加画面">
      ![Workgroup Create 03 Add Dialog](/images/workgroup-create_03_add-dialog.png "Workgroup Create 03 Add Dialog")
    </Frame>
  </Step>
  <Step title="ワークグループが追加されたことを確認する">
    「作成が正常に完了しました。」と表示され、ワークグループ管理画面の一覧の最後に追加されます。追加したワークグループは、有効になっています。

    <Frame caption="ワークグループ一覧">
      ![Workgroup Create 04 List](/images/workgroup-create_04_list.png "Workgroup Create 04 List")
    </Frame>
  </Step>
</Steps>

<Note>
  作成したワークグループに表示する項目は、[ワークグループ設定をする](/guide/admin/12741114939545)で設定します。
</Note>

解決しない場合は、[サポートチーム](#contact)にお問い合わせください。
