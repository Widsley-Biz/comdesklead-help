Comdesk Lead以外のシステムや、Excel・スプレッドシートなどで管理している顧客情報をComdesk Leadにインポートする際の注意点をご説明します。

<Info>
インポートの操作方法は、次のページをご参照ください。

- [リストをプロジェクトにインポート](/guide/admin/12743928066585)
- [リストを特定して上書きインポートをする](/features/advanced/12819542587929)
</Info>

## 1. リストの項目を整理する

画面左側の「Manage」メニューの「リスト項目設定」で、リスト項目（標準項目・カスタム項目）を設定できます。お手元のリストの項目と照らし合わせて、必要な項目を設定してください。

設定方法は次のページをご参照ください。

- [リスト項目設定で標準項目の表示を設定する](/guide/admin/12907898836249)
- [リスト項目設定でカスタム項目を作成する](/guide/admin/12738156781721)

<Tip>
各項目は、なるべく選択式で設定することをおすすめします。テキスト形式にすると、リスト項目での検索性が低下するためです。
</Tip>

## 2. ワークグループごとに表示するリスト項目を設定する

手順1で設定した項目について、ワークグループごとに有効・無効を設定してください。

設定方法は[ワークグループ設定をする](/guide/admin/12741114939545)をご参照ください。

## 3. お手元のリストの項目を整理する

手順1・2で設定したComdesk Lead上のリスト項目に合わせて、お手元のリストの項目と入力内容を整えます。次の点をご確認ください。

- Comdesk Lead上のリスト項目と、お手元のリストの項目が一致しているか
- Comdesk Lead上のリスト項目とデータ型が一致しているか（例：データ型が「数値」の項目に、お手元のリストでは文字列が入っている）
- Comdesk Leadにインポートできない禁止文字が含まれていないか

入力禁止文字の一例は次のとおりです。

| 文字 | 名称 |
| --- | --- |
| , | カンマ |
| ” | 半角ダブルコーテーション |
| ’ | 半角シングルコーテーション |
| `` ` `` | バッククォート |
| ’ | 全角/半角アポストロフィ |

<Note>
旧字体は、インポートできてもComdesk Lead上で正しく表示されない場合があります。
</Note>

## 4. お手元のリストをCSVファイルで保存してインポートする

お手元のリストをカンマ区切りのCSVファイルとして保存し、Comdesk Leadにインポートします。

インポート方法は[リストをプロジェクトにインポート](/guide/admin/12743928066585)をご参照ください。
