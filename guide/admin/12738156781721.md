---
title: "リスト項目設定でカスタム項目を作成する"
description: "標準項目にない項目を、カスタム項目としてリストに追加する手順を説明します。"
---

標準項目だけでは足りない項目は、カスタム項目として追加できます。カスタム項目は、作成したあとにワークグループへ適用すると、コールモード画面などで使えるようになります。

## リスト項目の種類

| 種類 | 説明 |
| --- | --- |
| 標準項目 | 初めから用意されている項目です。 |
| カスタム項目 | 自由に追加・作成できる項目です。 |

## 表示ラベルと項目名

| 名称 | 説明 |
| --- | --- |
| 表示ラベル | コールモード画面に表示される名称です。 |
| 項目名 | 内部処理で使用する名称です。 |

<Steps>
  <Step title="リスト項目設定を開く">
    画面左下の歯車アイコンを押します。［Manage］メニューが表示されたら、［リスト項目設定］を選択します。

    <Frame caption="［リスト項目設定］を選択">
      ![Custom Item 01 Manage Menu 1](/images/custom-item_01_manage-menu-1.png "Custom Item 01 Manage Menu 1")
    </Frame>
  </Step>
  <Step title="項目の追加を始める">
    ［リスト項目管理］タブを開き、画面右下の［＋］を押します。

    <Frame caption="画面右下の［＋］">
      ![Custom Item 02 Add Button 1](/images/custom-item_02_add-button-1.png "Custom Item 02 Add Button 1")
    </Frame>
  </Step>
  <Step title="項目の内容を入力する">
    ［項目編集］画面で、表示ラベルと項目名を入力し、データ型を選択します。入力したら、［変更］を押します。

    <Frame caption="［項目編集］画面">
      ![Custom Item 03 Item Edit](/images/custom-item_03_item-edit.png "Custom Item 03 Item Edit")
    </Frame>

    項目が作成されると、「作成が正常に完了しました。」と表示されます。
  </Step>
  <Step title="項目を適用するワークグループを選択する">
    ［適用するワークグループを選択］画面が表示されたら、項目を使うワークグループにチェックを入れ、［適用］を押します。すべてのワークグループで使う場合は、［全ワークグループ に適用］にチェックを入れます。

    <Frame caption="［適用するワークグループを選択］画面">
      ![Custom Item 04 Apply Workgroup 1](/images/custom-item_04_apply-workgroup-1.png "Custom Item 04 Apply Workgroup 1")
    </Frame>
  </Step>
</Steps>

<Note>
  作成した項目をワークグループの画面にどう表示するかは、[ワークグループの表示項目を設定する](/guide/admin/12741114939545)で設定します。
</Note>
