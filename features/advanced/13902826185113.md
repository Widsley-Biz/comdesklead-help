## 再コールリストの表示内容

再コールリストを開くと、対応状況が「予約中」「経過未対応」「コール済」の再コールが表示されます（初期状態では「キャンセル」は表示されません）。

  <img src="/images/スクリーンショット-2026-09-19-13.36.35.png" alt="画面左側のメニューから再コールリストを選択する画面" />
</Frame>

<Frame caption="再コールリストの対応状況">
  <img src="/images/スクリーンショット-2026-09-19-13.41.02.png" alt="再コールリストの一覧で対応状況列に経過未対応・コール済が表示されている画面" />
</Frame>

### 表示項目

一覧には次の項目が表示されます。

| 項目 | 説明 |
| --- | --- |
| 再コールID | - |
| 指定時間 | 再コールを設定した時間です。 |
| プロジェクト | - |
| 名前 | - |
| 電話番号 | - |
| 登録日 | 再コールを登録した日です。 |
| 登録者 | 再コールを登録したユーザーです。 |
| ステータス | - |
| 対応状況 | 再コールの対応状況です。 |

対応状況は、次の4つに分かれます。

| 対応状況 | 説明 |
| --- | --- |
| コール済 | 再コールを設定し、再度コールしたリスト |
| 経過未対応 | 再コールの設定時間を過ぎても、再度コールしていないリスト |
| 予約中 | 再コールの設定時間が未来のリスト |
| キャンセル | 再コール設定を解除し、再度コールしていないリスト |

### ユーザー種別ごとの閲覧・更新・削除範囲

ユニットを割り当てている場合、再コールリスト画面で閲覧・更新・削除できる範囲は、ログインユーザーのユーザー種別によって異なります。オフィス・ユニットの割り当て方法は、[ユーザーをオフィス・ユニットに割り当てる](/features/advanced/12790339370521)をご確認ください。

| ユーザー種別 | 閲覧 | 閲覧可能範囲 | 更新・削除 | 更新・削除可能範囲 |
| --- | --- | --- | --- | --- |
| システム管理者 | ◯ | 全情報 | ◯ | 全情報 |
| マネージャー | ◯ | 全情報 | ◯ | 全情報 |
| SV | ◯ | 全情報 | ◯ | 同じユニットに所属するユーザーが登録した再コール |
| リーダー | ◯ | 同じユニットに所属するユーザーが登録した再コール | ◯ | 同じユニットに所属するユーザーが登録した再コール |
| 一般ユーザー | ◯ | 同じユニットに所属するユーザーが登録した再コール | ◯ | ご自身で登録した再コールのみ |
| 退職者 | × | - | × | - |
| サポーター | × | - | × | - |

<Note>
- 閲覧権限がないユーザーには、再コールリスト自体が表示されません。
- 閲覧・更新・削除範囲は、オフィスではなく**ユニット単位**で判定されます。同じユニットであれば、所属するオフィスが異なっていても対象になります。ユニットが異なる場合は、同じオフィスでも対象になりません。
</Note>

ログインユーザーが「東京本社／カスタマーサポート」に、ほかのユーザーが「東京本社／カスタマーサクセス」に所属している場合を例に、「東京本社／カスタマーサポート」に所属するユーザーでログインしたときの表示を説明します。

  </Accordion>
  <Accordion title="SVでログインした場合">
    所属するユニットに関係なく、すべての再コールリストが表示されます。<br />同じユニットに所属するユーザーが登録した再コールを更新・削除できます。
  </Accordion>
  <Accordion title="リーダーでログインした場合">

## 再コールリストを検索する

再コールリストでは、条件を指定して検索できます。

<Steps>
  <Step title="フィルターアイコンを選択する">
    再コールリスト上部のフィルターアイコンを選択します。

    <Frame caption="フィルターアイコンと条件検索">
      <img src="/images/スクリーンショット-2026-09-19-14.02.29.png" alt="フィルターアイコンを選択して表示された条件検索パネル" />
    </Frame>
  </Step>
  <Step title="条件を指定する">
    検索条件を指定します。条件検索では、次の項目で絞り込めます。

    - 対応状況
    - ワークグループ
    - 名前
    - 登録者
    - ステータス（複数選択可能）
    - 指定時間
    - 登録日
  </Step>
  <Step title="検索する">
    ［検索］を選択します。指定した条件に一致する再コールが表示されます。
  </Step>
</Steps>

<Tip>
検索結果が表示された状態で、プロジェクト・名前・電話番号・登録者のいずれかの内容でさらに検索できます。複数の項目を組み合わせた検索はできません。
</Tip>

<Note>
対応状況を複数選択した場合は、選択した対応状況を一括で解除できます。
</Note>
