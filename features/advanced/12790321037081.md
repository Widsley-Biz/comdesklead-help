## 「オフィス」「ユニット」の概要

登録してあるユーザーを、オフィスやユニットごとに管理できます。
この記事では、「オフィス」「ユニット」の登録方法をご説明します。

<Tip>
「オフィス」「ユニット」をユーザーに割り当てる方法は、[ユーザーをオフィス・ユニットに割り当てる](/features/advanced/12790339370521)をご確認ください。
</Tip>

## オフィス作成

<Steps>
  <Step title="ユーザー管理を開く">
    画面左側の「Manage」アイコンをクリックし、「ユーザー管理」をクリックします。

    <Frame caption="Manageメニューのユーザー管理">
      <img src="/.gitbook/assets/12790321037081_0.png" alt="Manageメニューからユーザー管理を選択する画面" />
    </Frame>
  </Step>
  <Step title="グループ管理タブを開く">
    「グループ管理」タブをクリックします。

    <Frame caption="グループ管理タブ">
      <img src="/.gitbook/assets/12790321037081_1.png" alt="ユーザー管理画面のグループ管理タブ" />
    </Frame>
  </Step>
  <Step title="オフィス設定の追加ボタンをクリックする">
    オフィス設定欄の右端にある追加ボタンをクリックします。

    <Frame caption="オフィス設定の追加ボタン">
      <img src="/.gitbook/assets/12790321037081_2.png" alt="オフィス設定欄の右端の追加ボタン" />
    </Frame>
  </Step>
  <Step title="オフィス名を入力して変更をクリックする">
    オフィス名を入力し、「変更」ボタンをクリックします。

    <Frame caption="オフィス名の入力">
      <img src="/.gitbook/assets/12790321037081_3.png" alt="オフィス名の入力欄と変更ボタン" />
    </Frame>
  </Step>
  <Step title="登録を確認する">
    オフィスの登録が完了しました。

    <Frame caption="登録されたオフィス">
      <img src="/.gitbook/assets/12790321037081_4.png" alt="オフィス設定欄に登録したオフィスが表示された状態" />
    </Frame>
  </Step>
</Steps>

## ユニット作成

<Steps>
  <Step title="ユニット設定の追加ボタンをクリックする">
    ユニット設定欄の右端にある追加ボタンをクリックします。

    <Frame caption="ユニット設定の追加ボタン">
      <img src="/.gitbook/assets/12790321037081_5.png" alt="ユニット設定欄の右端の追加ボタン" />
    </Frame>
  </Step>
  <Step title="ユニット情報を入力して変更をクリックする">
    以下のとおり設定し、「変更」ボタンをクリックします。

    | 項目 | 説明 |
    | --- | --- |
    | ユニット名 | 必須入力項目 |
    | メールアドレス | 任意入力項目 |
    | API Key | 任意入力項目 |

    <Frame caption="ユニット情報の入力">
      <img src="/.gitbook/assets/12790321037081_6.png" alt="ユニット名・メールアドレス・API Keyの入力欄と変更ボタン" />
    </Frame>
  </Step>
  <Step title="登録を確認する">
    ユニットの登録が完了しました。

    <Frame caption="登録されたユニット">
      <img src="/.gitbook/assets/12790321037081_7.png" alt="ユニット設定欄に登録したユニットが表示された状態" />
    </Frame>
  </Step>
</Steps>
