---

活動履歴は、検索条件を指定して絞り込むことができます。

<Info>
活動履歴の確認方法は、[活動履歴の確認](/features/basic/12750509438233)をご参照ください。
</Info>

## 検索項目

| 項目 | 指定方法 |
| --- | --- |
| テキスト検索設定 | 顧客名・通話メモの検索条件を、前方一致か完全一致から選択します |
| コール日時 | 範囲指定 |
| 顧客名 | テキスト検索 |
| 発信先番号 | テキスト検索 |
| 発信元番号 | テキスト検索 |
| プロジェクト | プロジェクト名を選択 |
| 応対者 | 選択項目 |
| 再コール予定 | 範囲指定 |
| 通話時間 | 範囲指定 |
| 通話メモ | テキスト検索 |

## 検索方法

<Steps>
  <Step title="活動履歴を開く">
    画面左側のTeamsアイコンから「活動履歴」をクリックします。

    <Frame caption="Teamsメニューの活動履歴">
      <img src="/.gitbook/assets/12876176090905_0.png" alt="画面左側のTeamsアイコンのメニューで「活動履歴」を赤枠で示した画面" />
    </Frame>
  </Step>
  <Step title="検索条件ボタンをクリックする">
    検索条件ボタンをクリックします。

    <Frame caption="活動履歴画面の検索条件ボタン">
      <img src="/.gitbook/assets/12876176090905_1.png" alt="活動履歴画面の上部にある検索条件ボタンを赤丸で示した画面" />
    </Frame>
  </Step>
  <Step title="検索条件を入力して適用する">
    画面左側に検索条件画面が表示されます。検索条件を入力し、「適用」ボタンをクリックします。

    <Frame caption="条件検索画面">
      <img src="/.gitbook/assets/12876176090905_2.png" alt="画面左側に表示された条件検索画面と適用ボタン" />
    </Frame>
  </Step>
  <Step title="検索結果を確認する">
    活動履歴の検索結果が表示されます。

    <Frame caption="検索結果">
      <img src="/.gitbook/assets/12876176090905_3.png" alt="条件で絞り込まれた活動履歴の一覧" />
    </Frame>
  </Step>
</Steps>

その他ご不明点などございましたら、[**サポートチームまでお問い合わせ**](#contact)をお願い致します。
