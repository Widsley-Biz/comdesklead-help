## 着信の操作手順

<Steps>
  <Step title="待ち受け画面を確認する">
    待ち受け中の画面です。

    <Frame caption="待ち受け中の画面">
      <img src="/.gitbook/assets/14511279774745_0.png" alt="ComDesk Phoneの待ち受け中の画面" width="550" />
    </Frame>
  </Step>
  <Step title="着信を受ける">
    着信が入ると「外線着信」と表示され、次の情報が表示されます。

    | 項目 | 内容 |
    | --- | --- |
    | 日時 | 着信した日時 |
    | 回線名 | PBX Managerに登録している回線名 |
    | 回線番号 | 受電番号 |
    | 着信グループ | どのグループ宛の着信か |
    | 相手電話番号 | 相手先の電話番号 |

    受話器を上げるボタン（緑のボタン）をクリックすると、通話状態になります。

    <Frame caption="外線着信の画面">
      <img src="/.gitbook/assets/14511279774745_1.png" alt="「外線着信」の表示と着信情報、受話器を上げるボタンを赤枠で示した画面" width="550" />
    </Frame>
  </Step>
  <Step title="通話する">
    通話がつながると「通話中」と表示されます。

    <Frame caption="通話中の画面">
      <img src="/.gitbook/assets/14511279774745_2.png" alt="「外線着信（通話中）」と表示された画面" width="550" />
    </Frame>
  </Step>
  <Step title="通話を切る">
    通話を切る場合は、切電ボタン（赤枠）をクリックします。

    <Frame caption="切電ボタン">
      <img src="/.gitbook/assets/14511279774745_3.png" alt="通話中画面の切電ボタンを赤枠で示した画面" width="550" />
    </Frame>
  </Step>
  <Step title="待ち受け画面に戻る">
    通話が終わると、待ち受け中の画面に戻ります。

    <Frame caption="待ち受け中の画面に戻った状態">
      <img src="/.gitbook/assets/14511279774745_4.png" alt="通話終了後に戻ったComDesk Phoneの待ち受け中の画面" width="550" />
    </Frame>
  </Step>
</Steps>
