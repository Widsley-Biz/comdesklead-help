---

本記事では、パイプラインで管理する取引（リード）に表示する項目の設定方法をご説明します。

## パイプライン管理を開く

「Manage」メニューの「パイプライン管理」を開きます。

<Frame caption="Manageメニューのパイプライン管理">
  <img src="/.gitbook/assets/13940816117785_0.png" alt="Manageメニューからパイプライン管理を選択する画面" />
</Frame>

「リスト項目管理」タブには、上部に標準項目、下部にカスタム項目が表示されています。

<Frame caption="リスト項目管理タブ">
  <img src="/.gitbook/assets/13940816117785_1.png" alt="リスト項目管理タブの標準項目とカスタム項目の表示エリア" />
</Frame>

## 標準項目の編集

標準項目のうち、ラベル・製品名・初回商談日・連絡先担当者はON／OFFを切り替えられます。

<Frame caption="標準項目のON／OFF">
  <img src="/.gitbook/assets/13940816117785_2.png" alt="ラベル・製品名・初回商談日・連絡先担当者のON／OFFスイッチ" />
</Frame>

## カスタム項目の追加・編集

<Steps>
  <Step title="追加ボタンをクリックする">
    画面右下の「＋」ボタンをクリックし、項目編集画面を表示します。

    <Frame caption="カスタム項目の追加ボタン">
      <img src="/.gitbook/assets/13940816117785_3.png" alt="リスト項目管理タブ右下の「＋」ボタン" />
    </Frame>
  </Step>
  <Step title="項目を設定して変更をクリックする">
    項目編集画面が表示されます。各項目を設定して「変更」ボタンをクリックします。

    <Warning>
    フィールド参照値は、**半角英数のみ**で設定してください。
    </Warning>

    <Note>
    表示ラベルは自由に設定いただけます。
    </Note>

    <Frame caption="項目編集画面">
      <img src="/.gitbook/assets/13940816117785_4.png" alt="フィールド参照値・表示ラベル・データ型・データ値を設定する項目編集画面" />
    </Frame>

    データ型を選択すると、「データ値」に設定内容が表示されます。各データ型の内容は以下のとおりです。

    | データ型 | データ値 |
    | --- | --- |
    | テキスト | 一行フリーテキスト欄です（255文字以内）。 |
    | テキストエリア | 長文のテキストボックスです。行数を指定できます。 |
    | チェックボックス（T/F） | 質問を設定し、True（真）／False（偽）で入力できます。 |
    | 数値 | 数値のみを入力できるフォームです。 |
    | 選択リスト（ラジオボタン） | 選択肢の中から一つを選ぶラジオボタンです。 |
    | 選択リスト（セレクトボックス） | 選択肢の中から一つを選ぶセレクトボックスです。 |
    | 複数選択（チェックリスト） | 選択肢の中から複数を選択できるチェックボックスです。 |
    | 日付 | 日付の入力フォームです。カレンダーから入力できます。 |
    | 電話番号 | 電話番号の入力欄です。 |
  </Step>
  <Step title="追加した項目を確認する">
    設定したカスタム項目が表示されます。左側の歯車マークから、各項目を編集できます。

    <Frame caption="追加されたカスタム項目">
      <img src="/.gitbook/assets/13940816117785_5.png" alt="カスタム項目欄に追加された項目と左側の歯車マーク" />
    </Frame>
  </Step>
</Steps>

「リスト表示順」タブで、カスタム項目の表示順を設定できます。
