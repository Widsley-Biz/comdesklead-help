---
title: "多要素認証を設定する"
---

管理者は、［セキュリティ管理］でテナントの多要素認証（MFA）方式や認証を記憶する期間を設定できます。この記事では、多要素認証の設定内容と設定方法を説明します。

## 多要素認証の方式

テナントで使用する多要素認証の方式を、次の3つから選択できます。

| 方式 | 説明 |
| :-- | :-- |
| パスキー | FIDO2／WebAuthnに対応した認証方式です。共有PCでは、QRコードを使ったスマートフォンでの認証やハードウェアキーを利用できます。 |
| メールOTP | メールアドレスに届くワンタイムパスワードを使って認証します。 |
| MFA無効 | 多要素認証を使用しません。 |

パスキーを選択した場合、ユーザーは初回ログイン時にパスキーを登録します。初回登録とログインの方法については、[<u>パスキーを登録してログインする</u>](https://app.mintlify.com/comdesk/comdesk/~/7ab42c53-c5c3-4093-aca0-24e2811a96be)を確認してください。

## 多要素認証を設定する

1. ［セキュリティ管理］を開きます。
2. ［MFA設定］で使用する認証方式を選択します。
3. 設定を保存します。

すでにMFAが有効な状態でMFA設定を変更する場合は、変更を適用する前にMFA認証が必要です。画面の案内に沿って認証してください。

## MFA認証を記憶する期間を設定する

MFA認証に成功したあと、同じ端末で次のMFA認証を求めるまでの期間を設定できます。

1. ［セキュリティ管理］を開きます。
2. ［MFA記憶期間］で、次のいずれかを選択します。
   - 1セッション（ログイン時にMFA認証を要求する）
   - 1日
   - 7日間
   - 30日間
3. 設定を保存します。

デフォルトは［1日］です。

MFAの認証状況は、ユーザーと端末の組み合わせごとに記憶されます。<br />記憶期間内でも、別のPCからログインした場合はMFA認証が必要です。

## セッションの有効期限を設定する

ユーザーが操作を行わなかった場合に、セッションが終了するまでの時間を設定できます。設定はテナント内のユーザーに一律で適用されます。

1. ［セキュリティ管理］を開きます。
2. ［セッションタイムアウト］で、次のいずれかを選択します。
   - 30分
   - 60分
   - 90分
   - 120分
   - 240分
3. 設定を保存します。

セッション終了の5分前から、セッションを延長するための通知が表示されます。<br />通知から延長すると、再認証せずにセッションの有効期限が更新されます。
