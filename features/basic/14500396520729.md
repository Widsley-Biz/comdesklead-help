## SMS（ショートメッセージサービス）とは

通話だけでなく、お客様とつながるためのツールの1つです。

携帯電話の電話番号を使ってメッセージをやりとりでき、スマートフォン・ガラケーのどちらでも利用できるサービスです。

## メリット

| メリット | 説明 |
| --- | --- |
| ほぼ確実に相手に届く | 電話番号を間違えて送信している場合を除きます。 |
| 高い到達率／開封率90％ | 電話・はがき・E-mailに比べ、高い到達率／開封率が見込めます。 |
| 電話番号のみで送信可能 | キャリアを変更しても、電話番号が変わらない限りメッセージを送信できます。 |
| 携帯電話の機種に依存しない | アプリが不要なため、スマートフォン・ガラケーを問わず、どの携帯電話にも送信できます。 |

## デメリット

- **送信できる文字数に制限がある**<br />通常は半角160文字／全角70文字です。長文も送信できますが、その分課金されます。
- **画像・動画を入れられない**
- **件名を入力できない**
- **読んでもらえたかわからない**
